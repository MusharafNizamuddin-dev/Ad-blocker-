# CyberShield Android starter
Open this folder in Android Studio or AndroidIDE and build it.

Includes:
- CyberShield dark/neon app shell
- local HTML UI in WebView
- Android NotificationListenerService
- URL extraction from incoming notifications
- local heuristic verdicts
- no message-history database/storage

After installing, tap Enable Notification Access and enable CyberShield in Android Settings.

The exact original website source files were not available in the conversation/library search; screenshots were available. Once the real website HTML/CSS/JS files are supplied, put them in app/src/main/assets and the UI can be made an exact clone while keeping the native notification service.
